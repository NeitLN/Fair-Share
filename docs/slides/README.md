# Slides for Session 20 (T-37)

The 10-minute presentation of [ROADMAP §5](../ROADMAP.md#5-presentation-10-minutes-and-individual-defense),
in the brand's slide layout ([BRAND.md](../BRAND.md)): lilac content slides, one taro block each, ink text
of at least 28 px.

| File | Use |
|---|---|
| [`index.html`](index.html) | The deck. Open it in Chrome or Edge, press **F** for full screen |
| [`fair-share-slides.pdf`](fair-share-slides.pdf) | The same 9 slides as a PDF, in case the browser or the fonts fail on the class machine |
| `img/` | Screenshots of the live app at 390 px (22/10, a temporary household, deleted afterwards) |

**Keys:** → / Space / click on the right two thirds: next · ← / click on the left third: previous ·
**N** shows the speaker notes (who speaks, how long, what to say) · Home / End · `#4` in the address
opens slide 4. The fonts come from Google Fonts; without a connection the deck falls back to the system
font, which is why the PDF exists.

## Updating the PDF

After changing `index.html`, print it from Chrome (**Ctrl+P**, destination *Save as PDF*, margins
*None*, *Background graphics* on). Each slide becomes one 1920 × 1080 page.
