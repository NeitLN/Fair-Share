# Báo cáo kiểm thử thủ công — Fair-Share (bản deploy cuối)

- **Người kiểm:** Bùi Duy Anh
- **Thời gian kiểm:** 07/11/2026, 11h sáng
- **Bản kiểm:** https://fair-share-web.onrender.com
- **Tài khoản dùng:** tài khoản kiểm thử do Tiến cấp
- **Thiết bị:** laptop và điện thoại
- **Ngôn ngữ đã xem:** English và Tiếng Việt
- **Cách kiểm:** tự thao tác bằng tay từng phần, không dùng công cụ quét tự động.

## Kết quả

**Không tìm thấy lỗi chức năng hay lỗi giao diện** ở cả 20 phần đã kiểm bên dưới.

## Các phần đã kiểm

**Tài khoản**
- [x] Đăng nhập đúng / sai mật khẩu (báo lỗi rõ ràng)
- [x] Đăng xuất, tải lại trang vẫn ở trạng thái đúng

**Nhà (group)**
- [x] Trang chủ: danh sách nhà của mình
- [x] Tạo nhà mới
- [x] Mã mời: hiện mã, sao chép mã / đường dẫn
- [x] Người thứ hai xin vào → chủ nhà duyệt / từ chối

**Tổng quan**
- [x] Câu kết luận ("You owe …" / "Bạn cần trả …") đúng với số liệu
- [x] "Mark as paid" / "Đã trả" và Hoàn tác
- [x] Số dư từng người, lịch sử trả

**Chi tiêu**
- [x] Thêm khoản chi: chia đều, chia riêng
- [x] Số tiền kiểu `240k`, `2tr`, `1tr5`
- [x] Sửa / xoá khoản chi
- [x] Lọc theo tháng và theo người, tổng tháng
- [x] Xuất CSV (mở được bằng Excel)
- [x] Gõ nhanh bằng AI (điền form, hoàn tác điền)

**Thành viên**
- [x] Đổi tên, xoá thành viên (không xoá được người đã có trong khoản chi)

**Chung**
- [x] Đổi ngôn ngữ EN / VI (trong menu tài khoản), tải lại vẫn giữ
- [x] Giao diện sáng / tối
- [x] Bố cục trên laptop hiển thị gọn
- [x] Trên điện thoại: không bị cuộn ngang, nút đủ lớn để bấm
